# QuestMate — New Standalone App

This is a separate QuestMate Android project. It does not depend on the old QuestMate ZIP.

## Included
- One-button quest helper flow
- F2P OSRS quest list and search
- Quest details, requirements, items, locations, walkthrough and rewards
- OSRS Wiki guide links
- Floating draggable transparent-ish overlay
- Minimise to QM bubble and restore
- Opens OSRS Mobile when installed
- GPTracker price-checker screen that opens GPTracker for live prices

## Build
GitHub Actions builds the APK with Java 17 and Gradle 8.9.
